# Bookmark Bazaar

> Turn your abandoned bookmarks into a tiny marketplace of rotting curiosity.

You list unused browser bookmarks as for-sale curiosities with a freshness score that decays every hour. Other users bid, barter, or steal links before the URL goes stale and releases a smelly browser badge.

## Features
- Freshness decay engine that assigns hour-based value and visual rot states to bookmarks
- Import from browser export files and automatically tag topics from titles and domains
- Barter offers with counter-proposals and optional anonymous curiosity tokens earned by deleting stale links
- Public bazaar feed showing the most-rotted, most-bid, and most-stolen bookmarks

## Stack
- React
- Node.js
- SQLite
- Vercel

## Getting started
```
npm install, npm run db:seed, npm run dev, then deploy with vercel --prod
```
